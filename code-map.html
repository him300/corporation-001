Corporation 001 · the code

How the code fits together

Nine files and about 3,500 lines, no dependencies — Node's http and fetch are the whole stack. Two engines share one TypeSafe client; the browser is a dumb renderer of a payload the server already computed. Three more files are surfaces and tools, not machinery.

node server.mjs · market.mjs · replay.mjs · ohlcv.mjs · jev.mjs  ·  browser index.html · replay.js  ·  optional julia

01 The map

Dependencies point one way and never loop: the browser talks HTTP, the server imports the engines, the engines import the client. Nothing in the engine layer knows a socket exists.

03 The one mutable object

There is no store, no event bus, no persistence. freshMarket() returns this literal and every function takes it as its first argument and mutates it in place. 

// market.mjs:49 — the entire state of the simulation
m = {
  round: 12, mid: 99.83, fair: 100.04, quiet: 0,
  bid: 99.79, ask: 99.87, spreadBps: 8.0,
  book:   { bids: [{price, size} ×5], asks: [{price, size} ×5] },  // rebuilt every round
  levels: 10,                        // rows, both sides · 2…100, set by setDepth()

  tape:   [{ round, time, agent, side, size, price }],   // last 200 fills
  news:   [{ round, mid, text }],                        // last 12 headlines
  history:[{ round, mid, bid, ask, fair }],               // whole session, 8000 cap

  agents: [ { id, name, role, kind, maxSize, position, cash,
              pnl, fills, last: { action, probs, intent, size, bill } } ],

  stats:  { buys, sells, holds, volume, calls, fails },
  bill:   { pricePerMTok, round: {…}, total: {…}, byAgent: {…} },
  lastRoundMs: 348,
}

freshMarket() opens at mid 99.60 against fair 100.00 on purpose: a market with no gap and no headline is one where every agent rightly holds. The first headline arrives at round 0, so round 1 has something to read.

04 A replay is a job, not a request

A run takes minutes and costs money, so it cannot be one await behind an HTTP response. It becomes an entry in a Map, and the browser subscribes to its events.

request
POST /api/replay/run
body capped at 12 MB, CSV parsed on the way in
→
job
jobs.set(id, job)
events[], subscribers, cancel flag
→
work
runJob(job, params)
unawaited — the response returns the id immediately
→
stream
GET /api/replay/stream?id=
SSE: meta · bar · progress · original · surrogate · done
→
cancel
job.cancel = true
checked between bars and between surrogates

Events are buffered in job.events as well as pushed, so a late subscriber replays the backlog; /api/replay/result?id= answers the same job without a stream, which is exactly what the Telegram app uses. Surrogates run inside the same job, one full replay each.

05 The files

What each one exports, and the comment in it that explains the design decision.

market.mjs447 lines
ASSET · freshMarket · runRound · setDepth

The live engine. Constants at the top, brief() per agent, one round function that does news → calls → sizing → fills → reprice → mark.

“Always quote off the FIXED base width. Deriving the next width from the current bid/ask compounds the maker's multiplier into a runaway spread.”

replay.mjs349
DEFAULTS · replaySeries · compare

Walks bars forward, earns the previous bar's positions, asks five questions, sets target positions, charges cost, repeats. compare() computes every number in the surrogate table.

“There is no way to see the future from inside a brief, and the loop cannot be reordered without breaking that.”

server.mjs431
(entry point — no exports)

HTTP, SSE, one loop, four controls, replay jobs, optional ACCESS_TOKEN gate on /api/*, and static file serving for everything else.

“The one payload the UI renders. Keep it small — it ships every round.”

jev.mjs92
MODEL · getKey · systemOne

The only file that knows TypeSafe exists. Key resolution: env → a key file → .env, cached for the process lifetime.

“Any failure throws — callers decide the fallback.”

ohlcv.mjs342
parseOHLCV · parseTs · detectTimeframe · describe · returnsOf · seriesFromReturns · makeSurrogate · synthSeries · pathCorrelation · csvOf · rng

Column sniffing, timestamp parsing, median-gap interval detection, descriptors, and the built-in phase-randomiser used when Julia is missing.

“A surrogate keeps the statistical fingerprint of your data and none of its story.”

index.html1 036 lines
(the whole UI, inline)

Three theme token sets, the ladder, tape, news, chart, collective view, bill, and one EventSource that replaces S and calls render().

“Every colour is a CSS custom property, so nothing is duplicated per theme — including the canvas chart, which re-reads the active tokens on each draw.”

replay.js755
(browser only — no exports)

Drop target, a 400-row quick scan that pre-guesses the interval before the server sees the file, path drawing with its own pan/zoom, and the surrogate table.

Every surrogate is drawn in its own hue and can be brought forward — one surrogate, one path.

julia-surrogates.mjs59
juliaSurrogates

Spawns one Julia process per run, JSON on stdin, JSON on stdout, 120 s timeout. Every surrogate is generated in one call, so the ~8 s startup is paid once.

“Any failure throws and the caller falls back to the built-in phase-randomiser, so the app keeps working on a machine without Julia.”

personas.mjs · surrogates.jl · corp001.mjs · md2html.mjs13 · 68 · 189 · 163 lines
ROSTER · byId  |  the Julia program  |  init · status · fictional · csv · surrogates · refresh  |  the md → html template

The roster is shared so the live market and the replay always describe the same five participants. surrogates.jl maps six method names onto TimeseriesSurrogates.jl constructors. corp001.mjs is a client of the server, not a second implementation: it starts a run and reads the result. md2html.mjs is the manual's build step, in 163 lines with no markdown dependency.
